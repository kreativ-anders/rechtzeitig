All checks: imprint, consent, security and repository

Every rule has a fixed id, so you can refer to it in tickets. Open a card to see how it is checked, how to fix it and where the code lives.

Results

  • passNothing to do.
  • failrechtzeitig is sure something is missing or wrong.
  • warnA pattern matched that a person should look at.
  • infoA list of things to judge yourself.
  • skipThe check does not apply, for example no URL was given.

The severity says how much a finding matters, from info to critical. Website checks run when you give a URL. Repository checks run when the workflow checks out your repository first. Checks of repository and website together need both, and find what one side alone cannot show. Lockfiles read: package-lock.json, pnpm-lock.yaml, yarn.lock, composer.lock, pubspec.lock, Cargo.lock, uv.lock, poetry.lock, requirements*.txt, go.mod.

Sources are primary sources only: laws, courts, authorities, standards bodies, and vendor documentation for technical facts. Blogs and law firm articles are never cited. Each card shows when its sources were last reviewed; a rule not reviewed for a year fails the project's tests.

Overviews by topic: security headers, TLS and exposed files, and in German Kündigungsbutton, Widerrufsbutton und Bestellbutton.

What runs when

Checks that are off show as skip, with the reason and the setting that turns them on. A check marked Sends data asks an outside service; the badge links to what is sent.

Runs the axe-core rules listed for accessibility/alt-text in data/accessibility.yml on every visited own page with JavaScript on, inside the browser and without sending anything, and lists images, image buttons, image maps and SVG or ARIA images without a text alternative, with page and CSS selector; it only warns, since the BFSG does not apply to every site.
Scope
Website: runs with a url.
How to fix
Give every informative image an alt attribute that says what it shows, decorative images alt="". Image buttons (input type=image) and image map areas need alt too, SVG and role=img graphics an aria-label or title. Required by the BFSG for e-commerce services to consumers since 28 June 2025, except for microenterprises; useful for every visitor.

How it is checked
Lists <video autoplay> elements without the controls attribute on all visited own pages, loaded with JavaScript, and names those that are not muted as playing sound; it cannot see the video's length or custom play buttons, so it only warns.
